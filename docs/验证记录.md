- TypeScript 编译：API、Agent 通过。
- Vue 类型检查及 Vite 生产构建：通过。
- 6 项单元测试：密码哈希、错误密码拒绝、容器归属、审批角色不可进入他人容器、危险参数拒绝、签名内容绑定及超时拒绝、Docker 固定隔离参数。

## 尚需目标环境验收

- 两台学校服务器之间的网络路由与主机防火墙策略。
- 校园网门户、泛域名 DNS、有效 HTTPS 证书及 Agent 校内 CA 信任链。
- 持久化卷驱动的实际硬配额、掉电恢复和备份恢复。测试中的 tmpfs 有容量上限，但不持久化。
- 真实 Node/Python/Java 开发镜像中 Git、依赖下载、构建与应用兼容性；本地链路测试使用 BusyBox。
- 对各自 Linux 内核、Docker 版本和 IPv6 设置进行容器隔离检查。普通 Docker 不提供虚拟机级内核隔离。

测试脚本保留独立测试容器、数据卷和数据库记录，不执行自动删除。最终上线前必须替换测试参数，使用独立生产数据库和 Redis。
