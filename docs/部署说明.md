# 部署与运行说明

## 1. 架构与边界

管理节点运行 Vue 静态页面、Nginx、NestJS API、单个 BullMQ Worker、PostgreSQL、Redis 和 Traefik。两台计算服务器各运行一个 Agent，Agent 连接本机 Docker Unix Socket。首期按单 API 实例部署，不宣称控制面高可用。

```text
浏览器 → HTTPS Traefik → Nginx → Vue 页面 / API / 终端 WebSocket
                              ↓
                     PostgreSQL + Redis/BullMQ
                              ↓ 签名 HTTPS / WSS
                   Agent A             Agent B
                     ↓                   ↓
                  Docker A            Docker B

应用域名 → Traefik → 服务器管理网地址:动态端口 → 指定容器:申请端口
```

用户不持有宿主机账号和 Docker API 权限。Agent 只接受签名请求，并对参数做严格白名单校验。普通用户只能访问自己容器；审批人只能审批，不能借审批角色进入他人终端；维护管理员可以操作全部容器。

## 2. 管理节点配置

使用 Node.js 22、PostgreSQL 15+、Redis 6.2+。安装依赖后运行 `npm run build`。将以下变量通过服务管理器或密钥系统注入；不要将真实值提交到代码库。

| 变量 | 用途 |
|---|---|
| `NODE_ENV` | 生产使用 `production` |
| `DATABASE_URL` | PostgreSQL 连接串；外部连接使用受信任 TLS |
| `REDIS_URL` | Redis 连接串；可使用 `rediss://`，启用认证和持久化 |
| `PUBLIC_ORIGIN` | 用户访问门户的完整 HTTPS origin，不能带路径或尾部斜杠 |
| `APP_DOMAIN` | 应用泛域名，例如 `apps.example.edu` |
| `PORT` / `BIND_ADDRESS` | 默认 3000 / 127.0.0.1，仅供本机代理访问 |
| `GATEWAY_TOKEN` | 至少 32 字符随机值，仅给网关使用 |
| `IMAGE_TEMPLATES_JSON` | 模板名到审核镜像的映射，与 Agent 对应 |
| `SERVERS_JSON` | 节点 ID、Agent HTTPS 地址、密钥变量名和可调度预算 |
| `NODE_EXTRA_CA_CERTS` | 校内 CA 文件路径，用于验证 Agent 证书；不得关闭校验 |
| `BOOTSTRAP_ADMIN_USERNAME` | 首次初始化管理员用户名 |
| `BOOTSTRAP_ADMIN_PASSWORD` | 首次初始化密码，至少 12 字符；已有账号不会被覆盖 |

`SERVERS_JSON` 示例（仅示意，不包含真实凭据）：

```json
[
  {"id":"server-a","url":"https://agent-a.example.edu:3100","secretEnv":"AGENT_A_SECRET","cpu":12,"memoryMb":24576,"diskGb":500},
  {"id":"server-b","url":"https://agent-b.example.edu:3100","secretEnv":"AGENT_B_SECRET","cpu":12,"memoryMb":24576,"diskGb":500}
]
```

分别注入 `AGENT_A_SECRET`、`AGENT_B_SECRET`，每个至少 32 字符。预算应扣除操作系统和其他服务的占用；调度按已预留资源而不是瞬时 CPU 空闲量计算，避免并发超卖。

首次启动创建数据库表并初始化管理员。之后登录网站创建普通用户和审批人。登录令牌只保存在前端内存，刷新页面需重新登录；退出登录立即撤销 Redis 会话，已打开终端最多 5 秒内关闭。

## 3. Agent 节点配置

| 变量 | 用途 |
|---|---|
| `NODE_ENV` | 生产使用 `production`，缺少 TLS 文件即拒绝启动 |
| `AGENT_SHARED_SECRET` | 与此节点的管理端密钥一致，至少 32 字符 |
| `AGENT_TLS_CERT_FILE` / `AGENT_TLS_KEY_FILE` | 管理员提供的服务证书与密钥路径 |
| `AGENT_BIND_ADDRESS` / `AGENT_PORT` | 绑定管理网地址，默认回环 3100 |
| `DOCKER_SOCKET` | 默认 `/var/run/docker.sock` |
| `IMAGE_TEMPLATES_JSON` | 审核模板映射；镜像须由管理员预先加载，不自动拉取用户镜像 |
| `VOLUME_DRIVER` | 支持容量硬限制的持久化 Docker Volume 驱动 |
| `VOLUME_OPTIONS_JSON` | 驱动参数字符串映射；`{sizeGiB}` 替换为审批容量 |
| `APP_BIND_IP` | Docker 发布应用端口绑定的管理网 IP，默认回环 |
| `APP_UPSTREAM_HOST` | 网关可达的此服务器管理网 IP 或域名 |

模板映射示例：`{"lab-dev":"lab/dev:approved"}`。建议生产改用镜像 digest。可参考 `deploy/images/Dockerfile` 构建包含 Node、Python、Java、Git、ps/top 的开发镜像。镜像需满足 UID/GID 1000、`/bin/sh`、`sleep infinity`、`/home/developer` 可用，并使挂载后的数据目录归 UID 1000 所有。

Agent 的只读根文件系统防止用户修改系统包。Python 使用 `python3 -m venv ~/venv`；Node 使用项目内 `npm install`。需要 apt 或额外工具时，由管理员更新模板。

### 存储要求

Docker 默认 `local` Volume 不自动限制容量。必须为生产部署选择实际支持配额的持久化驱动，并按驱动文档配置 `VOLUME_OPTIONS_JSON`；参数名不是统一标准。上线前实际写入超额文件并确认驱动拒绝写入，同时确认容器重建仍保留数据。平台只检查驱动配置存在，无法代替该存储验收。

本地集成测试使用 `local` + `tmpfs` 的 `size` 限制验证流程；tmpfs 是内存临时盘，不得作为生产持久化方案。未配置配额驱动的节点不参与调度。

## 4. 网络、域名与网关

复制并在部署目录填写 `deploy/traefik.yaml.example`、`deploy/gateway.yaml.example` 和 `deploy/nginx.conf.example`。这些模板不会自动修改服务器。Traefik HTTP provider 使用 `Authorization` 请求头访问 `/internal/routes`，无需挂载 Docker Socket。

1. 管理员配置门户域名和 `*.apps.example.edu` DNS 指向网关。
2. 网关加载覆盖门户与应用域名的有效证书；校内 CA 证书须在客户端受信任。
3. API 仅对本机 Nginx/Traefik 可见，`/internal/routes` 不经门户代理公开。
4. 两个 Agent 端口只允许管理节点来源访问；SSH 只允许维护管理员的管理网络。
5. 宿主机应用动态端口只允许网关来源，不允许用户绕过网关直接连接。
6. 在 Linux 主机防火墙和 Docker 转发链配置容器出站策略：拒绝管理网、宿主机管理服务及其他租户网段，按需允许 DNS、代码仓库和依赖源。必须覆盖 IPv4/IPv6，不能只依赖 Docker 网络名称实现隔离。

创建容器时使用独立 Docker bridge，平台只发布已审批的单个 HTTP 应用端口。不同容器可以使用相同容器内端口。跨服务器代理使用管理网 IP，不能使用另一台机器无法路由的 Docker 私网 IP。

Traefik 每 5 秒刷新路由。超过 45 秒未获取容器状态、到期、停止或删除的容器不再出现在路由配置。后台停止容器同时撤销入口；Agent 独立执行到期停止，即使控制面离线也不会无限运行。

当前应用入口是校园网内可访问的 HTTP/HTTPS 服务，应用自身可实现登录；平台身份仅保护管理页面和终端，不会自动给每个用户 Web 应用增加登录页。公网访问需另行配置网络策略。

## 5. 任务恢复与数据保护

- 审批和资源预留使用 PostgreSQL 事务与锁，重复审批拒绝。
- `tasks` 表是事务消息表，每 10 秒补投队列，覆盖数据库提交后进程退出的情况。
- Agent 使用申请 UUID 生成固定 Docker 名称、数据卷和网络；创建重试识别已有资源。
- 任务指数退避重试四次，最终失败保留错误；管理员查询 `GET /api/tasks`，通过 `POST /api/tasks/:id/retry` 创建新任务。
- API 重启后从 Agent 同步实际状态。Redis 用于会话和任务执行，不替代 PostgreSQL。
- 删除容器会保留数据卷。创建中途失败也保留带平台标签的资源供幂等重试，不自动销毁用户数据。
- 数据库和数据卷均需独立备份。Redis 启用 AOF；丢失 Redis 会话会要求重新登录，待处理任务由数据库恢复。
- 本版只运行一个 API/Worker 实例；多副本之前需要扩展分布式操作锁和协调机制。

## 6. 运维接口与验证

健康检查 `GET /health` 会检查数据库和 Redis。管理员可通过网页查看节点状态和审计日志。业务状态保存在数据库，Agent 不伪造资源或返回 mock 容器。

验证顺序：构建与单元测试 → 本地真实依赖集成测试 → 校内两节点试运行 → 存储超额写入测试、网络越权测试、证书校验与恢复演练。容器隔离测试必须在授权测试容器内进行。

开发命令：`npm run build`、`npm test`、`node scripts/integration.cjs`。网关联调可使用 `TEST_GATEWAY=1 node scripts/integration.cjs`。测试保留已停止的容器及数据，不自动删除。

生产依赖原有 NestJS 10 已升级到修复漏洞的版本。不要继续沿用旧的演示用户请求头、内存数据或 `.env.example` 中的示例密钥。

## 7. 技术依据

- [Docker 安全边界与 Docker API 权限](https://docs.docker.com/engine/security/)：容器共享内核，Docker 控制服务属于高权限组件；禁用 CLI 本身不是权限隔离。
- [Traefik HTTP provider](https://doc.traefik.io/traefik/reference/install-configuration/providers/others/http/)：动态路由、轮询和认证请求头。
- [BullMQ Redis 连接](https://docs.bullmq.io/guide/connections)：后台 Worker 重连策略与 Redis 连接要求。
